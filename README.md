# TALdoc AI

Android offline document scanner + OCR + intelligent query.

Funzioni: import PDF/immagini, fotocamera, OCR offline (ML Kit), campo di ricerca grande multilinea, modalità Cerca / Trascrizione / Riassunto estrattivo / **Domanda intelligente** (rilevamento intento, estrazione entità, scoring preciso e risposta contestualizzata), export PDF/CSV, cancellazione sessione.

La modalità Domanda capisce richieste come "dammi l'indirizzo di SSI FACTORY", "qual è la paga base", ecc. e cerca in modo mirato (indirizzi, importi, date, nomi) nei testi OCR.

## Compilazione e download APK
GitHub Actions > Android APK > ultima run riuscita > Artifacts > TALdoc-debug-apk (app-debug.apk).

## Privacy
Nessun permesso INTERNET. Dati solo in cache privata. «Esci e cancella» rimuove la sessione.
