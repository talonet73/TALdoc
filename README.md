# TALdoc AI

Android offline document scanner + OCR + query.

Funzioni: import PDF/immagini, fotocamera, OCR offline (ML Kit), campo di ricerca grande multilinea, modalità Cerca / Trascrizione / Riassunto estrattivo / Domanda (contesto), export PDF/CSV, cancellazione sessione.

Ancora non disponibile: LLM locale per risposte generative complete.

## Compilazione
GitHub Actions > Android APK > Artifacts > TALdoc-debug-apk.

## Privacy
Nessun permesso INTERNET. Dati solo in cache privata. «Esci e cancella» rimuove la sessione.
